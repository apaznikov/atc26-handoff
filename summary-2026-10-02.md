# Summary of results, 2 Oct 2026

Speedup over stock TSan. AMD unless marked. Details, legs and audits are in `optimization-results.md`.

FE-INL, N1, DynSTC-RT, N1-ST and LO-OBJ-G were built before 1 Oct. Their figures here are the legs of record over
stock on the workload sets fixed on 30 Sep - 2 Oct. EVCONF, SWMR-ROOTS, the MySQL Release readings and every row of
tables 2 and 3 date from 1-2 Oct.

## Table 1. Gave a speedup

| idea | what it is | app | speedup |
|---|---|---|---|
| **DynSTC-RT + N1-ST**: single-thread mode in the runtime | While one thread is alive, all checks are skipped, range checks included | FFmpeg | +34.0 % (Intel) |
| **FE-INL**: inlined function entry/exit | TSan's per-call bookkeeping runs in the program, not in a runtime call | MySQL | +5.4 % |
| **FE-INL + N1**: plus inlined fast-path test | The "already recorded?" test also runs in the program | Redis | +7.6 % (Intel) |
| **SWMR-ROOTS**: globals written before readers start | No checks on reads if the only write precedes every reader thread | memcached | +0.9 % |

## Table 1a. Gave a speedup, based on annotations and premises

| idea | what it is | app | speedup |
|---|---|---|---|
| **EVCONF**: thread-owned objects under a guard | Checks on objects annotated as owned by one thread are skipped while a run-time guard holds | memcached | +32.2 % |
| **LO-OBJ-G**: lock-owned objects under a guard | Checks on objects annotated as protected by their owner's lock are skipped while that lock is held | SQLite | +16.9 % |

## Table 2. Gave nothing

| idea | what it is | app | result |
|---|---|---|---|
| **DE-REMOVAL, DE-3R, DE-2R** | Covered checks deleted; one check per loop; adjacent fields merged | MySQL / SQLite / memcached / Redis | +0.3 % / 0 / 0 / −3.8 % |
| **FE-HOT, HOT-LIST N1** | Inlining only in profile-hot code | SQLite, MySQL, memcached | worse than full inlining |
| **FE-PM** | Out-of-line register-preserving entry/exit | MySQL | −2 % (Intel −8 %) |
| **N1-L, VWIDE-loops, N1-ST, the paper's DynSTC** | Each added on top of the best configuration | Redis | −5…+1 %, none adds |
| **N1-ATOMIC** | Inlined test for atomic operations | Redis | +1.1 %, noise (Intel) |
| **EA-CONTENTS** | A pointer read from a container does not make the container shared | memcached | +1.3 %, noise (Intel) |
| **FE-LAZY** | Function entry recorded only if something happens inside | Redis | 0 |
| **InnoDB latches** | LO-OBJ-G for MySQL's own latches | MySQL | closed: ≤ 3.2 % of checks |
| **ODR trust** | Trust C++ inline function bodies for escape | MySQL | closed: 0.02 % of checks |
| **THREAD-IDS, LTO, Attributor, ICALL, NOALIAS, CUSTOM-SYNC, per-field SWMR** | More precise static analysis | all | closed: each < 3 % of checks |
